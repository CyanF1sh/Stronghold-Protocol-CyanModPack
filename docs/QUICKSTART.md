# 从零开始：怎么把「卫戍协议 · CyanFish 平台补丁与 Mod 集」跑起来

> **这份文档写给谁**：看了视频 / 帖子，知道有这么个开源项目，想**自己也跑一个**的人。
> 你**不需要会写代码**。这里只说清楚两件事：**你要凑齐哪些文件**、**你要依次做哪几件事**。
> 具体敲什么，每一步都有一份更细的文档指路（[INSTALL.md](INSTALL.md)）。

---

## 一、先明白这是个什么东西（免得白折腾）

- 这是《明日方舟》限时玩法「卫戍协议：盟约」的**非官方同人复刻项目**（上游叫 **Stronghold Protocol**）。
- **我们的仓不是游戏本体**，它是一层**"补丁 + 一堆小 Mod"**：本体得你自己准备，**官方素材也不在我们仓里**。
- 所以最终你要凑出来的是这么一套东西：

```
   【官方 0.2.6 本体】  ← 你自己准备（含官方素材）
            +
   【我们的补丁集】      ← 从我们的仓拿
            ↓  把补丁叠到本体上
   【能玩的服务器】      ← 能开服、能和朋友一起打
```

- ★ **版本必须严格对上**：我们这一版是**照着官方 0.2.6 一个字节一个字节对齐**做的。
  本体不是 0.2.6 ⇒ 补丁装不上、Mod 会被**整批丢掉**（这是设计，不是坏了）。
- ★ **不许盈利**。开服、直播、录像都行，但**不能收费**（详见 [NOTICE.md](../NOTICE.md)）。

## 二、你要凑齐哪些文件

一共**四样**。前两样是"东西"，后两样是"环境与素材"。

| # | 要什么 | 具体是什么 | 从哪来 | 多大 |
|---|---|---|---|---|
| 1 | **官方 0.2.6 本体** | 一份**干净、没被人改过**的官方 0.2.6 目录 | 官方仓库（源码）**或**官方发行包 | 22 MB ～ 560 MB |
| 2 | **我们的补丁集** | 我们这个仓：里面有 `overlay/`（补丁本体）、`mods/`（14 个 Mod）、`tools/`（几个小工具）、`docs/`（说明） | 本仓（下载即可） | 约 8 MB |
| 3 | **Node.js** | 官方要求 **22 或 24（长期支持版）**；装一次就行 | Node 官网，下 LTS 版一路下一步 | — |
| 4 | **官方素材** | 美术、模型、语音、字体等（**不在我们仓里，也不能由我们分发**） | 用官方自带的取素材工具**自己下**（约 550 MB，可中断续传） | ≈550 MB |

> 所以第 1 样**优先选"源码"那一份**：它和最完整的官方目录一致，我们后面"叠补丁"能一次过。
> 官方**整合包**也能用，但它为瘦身**删掉了测试与部分文档**，叠补丁时会被工具拦下来提醒你（有对策，见第五节）。

## 三、你要依次做哪几件事

### 第 1 件：弄到一份官方 0.2.6

去官方仓库（源码）或官方发布页（整合包），拿到 **0.2.6** 那一份，解压 / 放好。
**做完的标志**：你手上有一个目录，里面能看到官方的程序文件与一份 `package.json`，里头写着 `0.2.6`。

> ★ 这一步别急着开游戏。先确认它是 **0.2.6**、而且**你没手工改过里面任何文件** —— 第 3 件事会逐文件核对这件事。

### 第 2 件：把它跑一次，把官方素材下下来

官方自带一个**取素材**的工具（在它的 `tools/` 里）。第一次装依赖时会顺手把几个前端库放进 `public/vendor`，
再用取素材工具把**美术 / 模型 / 语音 / 字体**（≈550 MB）下到本体目录里。

**做完的标志**：本体目录里多了素材文件夹（`public/assets`、`public/fonts` 之类），而且 **`public/vendor` 里有 7 个文件**。
> 这一步最花时间，而且**可以中断**——重跑会从断的地方接着下。

### 第 3 件：把我们的补丁叠上去

把我们仓里那个**叠补丁的小工具**（在 `tools/` 里）指向**官方本体目录**跑一次。它会：

1. **先自己体检**：看补丁文件有没有下坏；
2. **再核对你的本体**：确认本体里那些文件**还是官方原样**（你没改过）—— 有对不上的就**停下来不写**；
3. **先备份、再覆盖**：把要改的文件都留一份备份（备份目录就在本体目录里），随时能整个还原；
4. **顺手把那 14 个 Mod** 拷进本体的 `mods/` 目录（默认全部启用）。

**做完的标志**：本体目录里出现了 `mods/`（14 个 Mod 目录），校验工具报 **"14 个 Mod 全部通过"**。

> ★ **直接用官方整合包的人注意**：工具可能会报十来个"文件不存在"的冲突。那是因为整合包删过测试与文档，
> 而我们的补丁清单是按**源码目录**核对原样的。**这不是装坏了**——换源码那一份，或者在工具上加"强制"开关（那些文件只影响测试与文档，不影响玩）。

### 第 4 件：起服，开玩

按官方的正常方式把服务器起来（官方目录里的启动脚本 / 官方文档里那条命令）。起来之后浏览器开
**本机地址的 3000 端口**就能打了。

**做完的标志**：浏览器里出现游戏界面、能建房开局。

## 四、可选：想让别人也能进来

| 场景 | 要做什么 |
|---|---|
| **同一台电脑** | 不用做任何事，直接开本机地址 |
| **同一个局域网**（家里 / 宿舍） | 把内网地址发给对方；**记得在系统防火墙里放行 3000 端口** |
| **公网（异地朋友）** | 有公网 IP：在路由器 / 云主机控制台做**端口映射**（外部端口 → 内网 3000）；<br>没有公网 IP：用**内网穿透**（例如 Cloudflare 的临时隧道，或 frp / tailscale 这类工具） |

**★ 公网开服两条安全底线**
1. **管理页默认是关的**（见下节）。公网暴露前先想清楚要不要开它、令牌给谁。
2. 这是**非官方**项目，公网开服的风险（被扫、被攻击、被举报）**由你自己承担**；**任何形式收费都不允许**。

## 五、可选：Mod 管理页

我们带一个 **Mod 管理页**（查房间明细、在线趋势、开关 Mod）。它**默认不启用** ——
你得先给服务器设一个"管理令牌"（一串自己编的、别太短的口令），它才会挂出来。
挂出来之后，浏览器开服务器的 `/admin`，把令牌粘进页面里的令牌框就能用（令牌只走请求头，不会出现在网址里）。

---

## 六、可选：皮肤与语音（`cyanfish.skinvoice`）

我们仓里**一个官方素材都没有**。所以那个"换皮肤 / 换语音"的 Mod，**只带代码，不带素材** ——
官方皮肤与语音要**你自己准备**（放哪里、怎么放，看那个 Mod 目录里的说明）。

> ⚠️ 它的毛病很隐蔽：**素材没放齐时，服务器一切正常**（健康检查、Mod 列表全绿），
> 只有**干员皮肤在名单里显示不出来、局内也换不上**。

## 七、卡住了对照表

| 你看到的 | 多半是什么 | 往哪想 |
|---|---|---|
| 页面**全白** | 前端库没就位（`public/vendor` 那 7 个文件缺） | 重装依赖，或单独跑官方的 vendor 工具 |
| 提示**版本不是 0.2.6** | 本体版本不对 | 回第 1 件，确认是 0.2.6 |
| Mod 列表里**一片被跳过** | Mod 声明的游戏版本和本体对不上 | 版本必须**严格相等**，这是设计 |
| 叠补丁时报**一堆"文件不存在"** | 你用的是官方整合包（它删过测试与文档） | 换源码那一份，或加"强制"开关 |
| 起服说**端口被占** | 3000 被别的程序占了 | 换一个端口 |
| 素材**下到一半断了** | 正常 | 重跑取素材工具，会续传 |
