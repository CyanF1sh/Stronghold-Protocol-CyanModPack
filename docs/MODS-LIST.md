# 14 个 Mod 逐条清单

> 14 个 Mod **几乎全是纯文本**（`.js` / `.mjs` / `.json` / `.md` / `.html`）：**不含**官方美术、语音、音乐、字体或官方数据表拷贝。
> ★ **唯一例外**：`cyanfish.dj-all/assets/amiya-spin.gif` —— 1 张 **128×128 同人二创表情包**（117 KB · 局内入口图标）；**若侵权可联系删除**，来源见该目录的 `assets/图标说明.md`。
> **14 个全部正常装载**（`gameVersion` 全为 **0.2.5**）· 装完**默认全部启用**。
> `tools/apply-overlay.mjs --with-mods` 会把 14 个目录全部拷进 `mods/`。

★ **收录口径**：本仓的 Mod 以**作者正式服上线的**为主，另有**三类例外**：
- **样例包** `cyanfish.demo`（想自己写 Mod，从这个包开始读最省事）；
- **代码进仓、官方素材自取**：`cyanfish.skinvoice`（随包只有代码与目录 —— **官方皮肤/语音素材请自行准备**）；
- **作者亲自收录、尚未上线**：`cyanfish.dj-all`（纯界面整活）· `cyanfish.music-overlay`（音效替换，音频由玩家**自己上传**）。
因此：
- **未部署**的实验性 Mod（只在测试实例跑的、退役的、上游已自行修复的）**不在**本仓；
- **自带官方 / 联动素材副本**的 Mod **不在**本仓（★ 例：`cyanfish.dj-all` 原包 `assets/` 下两张第三方角色动图**未随本仓分发**，见该目录的 `assets/图标说明.md`）。

> ★ 完整的 Mod 清单（含**未发布**内容）见覆盖层里的 `overlay/docs/MODS.md` **§12** —— **那是作者树的快照，不是本仓的发布清单**。以本文件为准。

## 二、怎么自己改启停

```bash
# ① 用 CLI（推荐）
node tools/mod.mjs list                    # 看状态
node tools/mod.mjs disable cyanfish.demo   # 停用
node tools/mod.mjs enable  cyanfish.demo   # 启用
```

```jsonc
// ② 直接改 mods/.state.json（本机启停状态，不随 Mod 分发）
{ "version": 1, "disabled": ["cyanfish.demo"], "order": [] }
```

③ 删掉 `mods/.state.json` ⇒ 回到「**全部启用**」。

★ 覆盖层的 `apply-overlay.mjs` **不写** `mods/.state.json`（14 个默认全开）。

## 三、兼容性

- 14 个 Mod 的 `mod.json` **全部**写 `gameVersion: "0.2.5"`；
- **装载器要求 `gameVersion` 与本版游戏版本严格相等**，否则**整包被跳过** ⇒ **游戏本体必须是官方 0.2.5**；
- 用 0.2.4 或更早：**14 个 Mod 会被整批拒装**。

装完自检 `node tools/mod.mjs validate` 的预期输出 = **14 个全部通过 · 0 错误** · 退出码 **0**。
