# 21 个 Mod 逐条清单

> 21 个 Mod 全是**纯文本**（`.js` / `.json` / `.md`），**零素材**：不含美术、语音、音乐、字体或官方数据表拷贝。
> 装完之后的实际状态分三类：**12 个正常装载** · **2 个整活被版本门槛跳过** · **7 个历史归档默认停用** ⇒ 合计 21 个目录。

`tools/apply-overlay.mjs --with-mods` 会把 21 个目录全部拷进 `mods/`，并在 `mods/.state.json`
**不存在**时写一份把第三节那 7 个停用的状态（与作者两台实例的口径一致）。它们仍然在 `/mods` 里**可见**。

## 四、怎么自己改启停

```bash
cd "<游戏目录>"
node tools/mod.mjs list                 # 看状态
node tools/mod.mjs enable  <mod-id>     # 启用某一个
node tools/mod.mjs disable <mod-id>     # 停用某一个
```

`mods/.state.json` 是**本机启停状态**（属于你的机器、不随 Mod 分发）；删掉它等于「全部启用」。

## 五、兼容性

- 上游本体必须是 **0.2.5**（12 个生效 Mod 的 `gameVersion`，另有 7 个归档也是 0.2.5）；
  两个 DJ 是 **0.2.4** ⇒ 会被装载器跳过。
- 21 个 Mod **都不依赖官方素材**；改数值的 Mod 只改**数据**，不触碰美术。
