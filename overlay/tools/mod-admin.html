安装 Mod ?

.spmod 单文件包
把 .spmod 拖到这里，或点击选择文件
上限 32 MB

安装后需要「重载」或「重启进程」才会生效。

怎么写一个 Mod？

一个 Mod 就是一个目录，最少两个文件：

my.mod/
  ├─ mod.json                 清单：id/name/version/apiVersion/gameVersion
  ├─ data/chess.json          数据补丁：{ "ops": [ … ] }
  ├─ content/index.js         可选：L3 行为代码（新技能机制）
  └─ assets/                  可选：自带美术，/assets/ 未命中时按 Mod 顺序兜底

# mod.json
{ "id": "my.mod", "name": "显示名", "version": "1.0.0",
  "apiVersion": 1, "gameVersion": "0.1.2",
  "author": "你的名字", "description": "一句话说明" }

# data/chess.json —— 从现有干员克隆一名新干员，再改数字
{ "ops": [
  { "op": "clone", "from": "chess_char_1_01_a",
    "path": "my_op_a", "value": { "name": "我的干员", "visible": true } },
  { "op": "deepMerge", "path": "my_op_a.stats", "value": { "atk": 999 } }
] }

# 本地先校验再打包（不通过不给打包）
node tools/mod.mjs lint <你的Mod目录>
node tools/mod.mjs pack my.mod -o my.spmod

可用操作：add 新增 · clone 复制已有记录再覆盖 · replace 替换 · merge / deepMerge 字段级合并 · remove 删除 · append 往数组幂等追加（专用于盟约成员表）。

维护

「重载 Mod」不重启进程，秒级生效；客户端本地跑战斗，玩家需刷新页面才能拿到同一份数据。「重启进程」会断开所有连接，由 systemd 在 1~2 秒内重拉。
