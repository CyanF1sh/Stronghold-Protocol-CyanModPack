## 原始说明（0.1.2 时代，保留供追溯）

修《网页端bug清单v1.0》第③条。深海敌人「深溟巢涌者」与「富营养的巢涌者」在官方数据里**没有普通攻击** ——
它们的输出是「持续对周围造成法术伤害和神经损伤」的光环（`data/enemies.json` 里 `acType = DOT`、`skills` 为空；
描述原文『持续对周围造成法术伤害和神经损伤；抵抗，且移动速度不会降低』）。但基座把这条光环挂在**普攻流程**上
（`kitDsubrl` 用 `beforeAttack` 钩子改写普攻目标），于是这两个单位会抬手、播攻击动画、停下来打人，
还会被麻痹打断、被攻速影响。本 Mod 关掉它们的普攻，改由自己按固定 1 秒节奏驱动同一套伤害
（法术伤害 + 神经损伤，范围与可选性判据与原先逐项一致）⇒ 输出总量不变，但不再是普攻。

纯 L3 行为 Mod，无数据补丁、无美术。逐条实现见 `content/index.js` 顶部注释。
