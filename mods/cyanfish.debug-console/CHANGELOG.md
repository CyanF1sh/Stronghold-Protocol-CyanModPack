- 「敌人」页重做：-5 / -1 / +1 / +5 改数量，类别与已添加 / 未添加两个下拉框筛选
- 「干员」「装备」页按 1~6 阶筛；一行只显示名字与 id 前缀，右侧「普通 / 精锐」各发一个
- 「基础」页快捷档收窄：回合 1/14/15、资金 325/799/999、生命 1/策略初始值/99
- 「悬赏」页只列会给敌人或我方干员上常驻效果的卡，改用开关切换（加敌人去「敌人」页）
- ★ 玩家可见的变化到此为止；本版同时给基座补了三条调试接缝（见报告 115）
