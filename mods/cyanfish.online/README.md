# cyanfish.online — 首页在线人数（L4 + 一条数据补丁）

在首页（选择模拟协议）顶栏左边、延迟读数旁边加一枚小胶囊：

```
● 42ms   在线 3 · 房间 1 · 对局 1
```

鼠标悬浮看完整拆解：连接 / 会话 / 座位上的真人 / AI 队友 / 观战 / 单房间人数上限 / 运行时长。

## 数字从哪来（★ 只有一个真相）

`GET /healthz` —— 宿主**已有的**只读状态接口（`server/http/routes.js` 的 `healthReport`）：

| 显示 | 字段 | 真实来源 |
|---|---|---|
| 在线 | `sessions`（取不到时退到 `sockets`） | `SessionRegistry.size` —— **已握手**的会话数，**含观战** |
| 房间 | `rooms` | `Lobby.rooms.size`（= 同盟数） |
| 对局 | `matches` | 已有 `Match` 的房间数 |
| 悬浮拆解 | `sockets` / `humans` / `bots` / `spectators` / `maxSeats` / `uptimeSec` | 同上 |

- **没有为本 Mod 新增任何端点**，也没有第二份真相（与 docs/MODS.md §4.12.2 四同一条口径）。
- 判据是「`rooms` 存在且是数字」：连它都没有 ⇒ 这不是我们认识的 `/healthz`（老服务端 / 反代改了响应）⇒ **整枚胶囊不渲染**，绝不拿默认值冒充。
- 单个字段缺失 ⇒ 那个数字显示 `—`（拆解行里），胶囊上则不出现那一段。

## 开销（为什么是 20 秒）

| 项 | 数 |
|---|---|
| 一次请求 | `GET /healthz`，响应约 **200 字节**（实测，见 `<开发期报告>/61-announce-stats-and-audit.md`） |
| 频率 | 每客户端 **1 次 / 20 秒**（页签可见时；隐藏时 0） |
| 100 个在线客户端 | **5 次/秒**、约 1 KB/s 下行 —— 与服务端自己承担的广播流量相比可忽略 |
| 服务端成本 | 一次 `/healthz` = 遍历房间算计数（`Lobby.stats()`，房间数级循环）+ 一次 `JSON.stringify`；实测见报告 |

轮询间隔在数据里（`online.pollSec`），夹在 **5~300 秒**之间 —— 再密就是拿服务器换毫无意义的实时性。

## 数据补丁（`online` 段）

```json
{ "ops": [ { "op": "add", "path": "online", "value": {
  "enabled": true,
  "pollSec": 20,
  "showMatches": true
} } ] }
```

| 键 | 含义 | 非法 / 缺省时 |
|---|---|---|
| `enabled` | 总开关。**显式 `false`** 才关（写坏了按开处理） | 开 |
| `pollSec` | 轮询间隔（秒），夹在 `5 ~ 300` | `20` |
| `showMatches` | 是否显示「对局 K」那一段（为 0 时本来就不显示） | `true` |

## 边界（诚实登记）

- **只统计本服务器进程**：`/healthz` 报的是这一台实例的连接与房间；多实例部署时每台各自算。
- **「在线」包含观战者**，也包含同一玩家的多个页签（那是**会话**数，不是人数）—— 想只看座位上的真人，悬浮拆解里的「座位上的真人」才是那个数。
- **拿不到就什么都不显示**：静态托管（没有游戏服务）/ 老服务端 ⇒ 胶囊不渲染，页面与没有这条插槽时逐字节相同。
- **连续 3 个周期失败只变暗**（`.is-stale`），读数是最后一次成功的值 —— 消失会让玩家以为服务器挂了。
- **悬浮用原生 `title`**（多行）：宿主自己的延迟胶囊就是这么做的，两枚并排观感一致；本 Mod 不画自有气泡。
- **只在首页**：对局中看不到（那条插槽只挂在首页顶栏）。

## 零痕迹（不装这个 Mod / 关掉它）

- 没装 / 停用 ⇒ 该模块根本不会被 `extensions.js` import；
- 装了但 `enabled: false` 或从未读到 `/healthz` ⇒ 组件返回 `null` ⇒ Preact **不产生任何节点**；
- 样式只在**真的要画**时才注入 `<head>`（幂等，按 id 判断）。

## 文件

|---|---|
| `mod.json` | 清单（`gameVersion` 必须与宿主 `package.json` 逐字符相同） |

| `client/plan.js` | 纯逻辑：清洗 /healthz / 段构造 / 悬浮文案（可离线逐条断言） |

| `client/style.js` | `.sp-on*` 样式（几何复刻宿主 `.ping`，两枚胶囊并排观感一致） |
