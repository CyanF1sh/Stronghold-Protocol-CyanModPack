# 素材出处（来源与校验）

本 Mod **只带一个美术资源**：局内入口的图标 —— **同人二创「表情包」素材**（角色「阿米娅」，出自《明日方舟》）。

★ **定性先说清楚**：它**不是官方素材** —— 不是鹰角 / Yostar 发布的立绘、头像、Spine 或 UI 资源，也不是官方客户端转储；
它也不是普通的同人插画，而是**社区流通的同人二创表情包（梗图）**。这类素材的特点是**本身就是以「供同好自由转发使用」为目的做出来的**。
（角色「阿米娅」及其形象本身的版权仍归鹰角网络 / Yostar —— 二创不改变原始 IP 的归属。）

按 `docs/MODS.md §7.4`（出处与授权，**必须**）给出逐文件出处、哈希与使用限制。

## 来源

- 这两份文件由**服主（本服务器所有者）**提供并放入 `assets/`，用作本 Mod **局内入口那颗图标键**。
- 它**是**：**同人二创表情包（梗图）素材** —— 玩家社区里自己画 / 自己做的、供同好自由转发的二创图。
- 它**不是**：
  - 鹰角 / Yostar 发布的官方资源（立绘 / 头像 / Spine / UI）；
  - 官方客户端的素材转储（不是 `char_*/avatar|portrait|spine` 那一类）；
  - 本仓库 / 本会话产生的任何东西。
- **画师信息未标注**（素材本身不带署名）。⇒ 如果服主能补上画师名 / 主页，本文件会补记（**更尊重原作者，欢迎补充**）。
- 本会话对 `assets/amiya-spin.gif` **只做了「缩放 + 调色板重编码」，没有做任何改动式再创作**：
  帧数（27）、帧率（10 fps）、时长（2.70 s）、循环方式（无限）、透明通道与源文件**逐项一致**。所用命令原样留档：

  ```bash
  ffmpeg -y -i "阿米娅旋转.gif" \
    -vf "scale=128:128:flags=lanczos,split[s0][s1];\
  [s0]palettegen=max_colors=128:stats_mode=diff[p];\
  [s1][p]paletteuse=dither=bayer:bayer_scale=4:diff_mode=rectangle" \
    -loop 0 "amiya-spin.gif"
  ```

  （理由：960×960 的 27 帧动图当 44 px 图标太重 —— 全解码约 100 MB 级，而它只显示在 38 px 的圆里。
  压后体积 **1.8 MB → 117 KB**，缩小约 15 倍。）
