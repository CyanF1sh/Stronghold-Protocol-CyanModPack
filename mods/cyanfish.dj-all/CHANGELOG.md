# 全局整活（所有可见元素可配置旋转）

## 1.0.1 — 2026-10-14
- ★★ **换面的横向口径按服主实测改正**：横向**永远用带符号的 `cos θ`**，**不再**在挂背面时把 `cos θ` 换成 `|cos θ|`。
  服主原话：「在**整备阶段**不会调用干员的背面切换，此时**仅翻转**；但是在**战斗阶段**，实际上的**背面资产是对称而非旋转 180°**，
  也就是说，不需要将 cos θ 改为 |cos θ|，而是**直接额外调宿主 setDir()**。」
  ⇒ 现阶段行为 = **既切换正反、又进行镜像**（换面只负责换成背面资产，镜像交给 `scale.x` 的符号）；
  整备阶段（`prep`）仍**不调** `setDir()`、仅翻转（这一条本来就在"绝不碰"名单里）。
- 该口径导出成常量 `FB_HORIZONTAL_SIGN`，由门禁 `dj-all-028-fbunit.mjs` 直接断言（将来要恢复 `|cos θ|` 只改这一行）

## 1.0.0 — 2026-10-14
- ★★「随机偏移」的随机落到**元素实例**上（不再是"目录里的那一项"）——
  · **画布对象**（干员 / 敌人 / 召唤物 / 装置 / 特效）按 `view.uid` **逐对象**算幅度与初相位
    ⇒ 干员 A 与干员 B 不同，**场上两个同名干员也不同**；关掉随机时回到"全组同步"
  · **DOM 元素**用 `:nth-child(1..8)` **位置桶**：同为兄弟的重复实例（队伍列 / 商店卡 / 角落四键…）各错各的
- ★ DOM 侧 CSS 结构重写：**三条通用 keyframes**（压缩深度 / cos / 平面内角）+ 每个实例自己的
  `--sp-dja-m` / `--sp-dja-w` ⇒ 同一段 CSS 服务所有实例，CSS 体积反而大幅下降
- 新增自省读数：`__SP_DJALL__.instProbe(gid)`（某分组前 N 个目标此刻的实例键/幅度/相位）、
  `engineStats().pixi.instanced`（本帧用了逐实例参数的目标数）
- 修（这两条都是本轮自己探针抓到的、上线前就修掉了）：
  · `transform` 的 `calc()` 里自定义属性漏了 `var()` 包裹 ⇒ 浏览器**静默丢弃整条 transform**（DOM 完全不动）
  · 位置桶选择器的作用域前缀漏了尾空格（`.screen.gm.team`）⇒ 一条变体都匹配不上（所有实例完全一致）
